## What It Does

MiMo Code is Xiaomi's terminal-native coding agent built as an OpenCode fork. It adds cross-session memory and voice input while maintaining a command-line focused development workflow. Released under the MIT license, the project reports strong performance on SWE-Bench Pro and Terminal-Bench 2 benchmarks.

### Key Features

- **62% SWE-Bench Pro** — Strong software engineering benchmark performance
- **73% Terminal-Bench 2** — Competitive terminal-agent benchmark results
- **Cross-session memory** — Retains context across sessions
- **Voice input** — Supports voice-driven interactions
- **MIT licensed** — Fully open source
- **Terminal-native UI** — Designed for command-line workflows
