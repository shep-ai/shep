$ shep harness --help
Usage: shep harness [options] [command]

Query-aware agent harness (experimental): standalone tasks, context plans,
permissions

Options:
  -h, --help                    display help for command

Commands:
  init [options]                Set up a repository for the harness (writes only
                                under .shep/harness/)
  run [options] <task>          Run a standalone task in its own worktree
  resume [options] <id> [task]  Continue a standalone session with a follow-up
                                instruction (or retry its last goal)
  stop <id>                     Stop the running task of a session before its
                                next turn
  apply [options] <id>          Commit a standalone session's changes to a
                                branch (nothing is pushed)
  promote [options] <id>        Continue a standalone result as a feature (spec
                                → review → PR)
  discard <id>                  Remove a standalone session's worktree (its
                                state and evidence are kept)
  ls [options]                  List harness sessions
  inspect                       Inspect sessions and context plans
  view [options] <chunk-id>     Render a chunk at a visibility level (from
                                stored output; nothing re-runs)
  explain [options] <id>        Why a decision came out the way it did
  permissions                   Answer and review permission requests
  capabilities [options]        The tiered tool catalog the agent sees
  policies [options]            Effective permission rules for a repository
  eval                          Paired evals: baseline vs query-aware on the
                                same tasks
  help [command]                display help for command
