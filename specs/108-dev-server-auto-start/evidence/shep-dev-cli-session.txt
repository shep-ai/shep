$ shep dev --help


Usage: shep dev [options] [command]

Run and inspect a local dev server

Options:
  -h, --help        display help for command

Commands:
  start [options]   Start the dev server and stream it until it is ready
  stop [options]    Stop the dev server
  status [options]  Show the dev server state and the command it runs
  logs [options]    Show the dev server output
  plan              Inspect, pin or clear the resolved run plan
  help [command]    display help for command

$ shep dev plan --help


Usage: shep dev plan [options] [command]

Inspect, pin or clear the resolved run plan

Options:
  -h, --help       display help for command

Commands:
  show [options]   Show the resolved run plan
  set [options]    Pin a run plan of your own
  clear [options]  Clear the cached run plan so the next start re-analyzes
  help [command]   display help for command
