Open question · the name

Make it feel familiar

People adopt the boldest thing they can still understand at a glance. The familiar part does the most work in three places: the one-line pitch, the words on screen, and the name. Those are in order of how much they matter.

1 · The pitch, borrowed from something every GitHub user knows

Dependabot for your backlog.

Dependabot already opens pull requests while you sleep. Shep 2 does the same for your issues, with your own coding agent.

2 · The words: GitHub's, not ours
We sayissue · task · pull request · merge · send back · tonight
We stop sayingfeature · spec · SDLC · fleet · worktree · agent run · space · autopilot
3 · The name
RecommendedShepshep add "#412"

Four letters to type, like git. A shepherd keeps watch at night, so the story fits. The pitch carries the meaning the name doesn't.

Nightshiftnightshift add "#412"

Says the job outright. The npm name is free. It clashes with Apple's Night Shift setting on every Mac and iPhone, and it's long to type.

Overnightovernight add "#412"

Says the promise. The npm name is taken, and it's even longer to type.

How to decide: show 5 developers the name plus the pitch for five seconds, then ask what it does. Keep whichever they explain correctly.

Rules

Three rules that keep it small

Draft PRs only. You press merge.

Agents run unattended with permission prompts off, so nothing reaches main without a person.

Same four actions everywhere.

If a surface needs something the core doesn't offer, the core changes for all four, or the idea waits.

Budget, not backlog.

4 commands, 5 states, 1 page, 3 tools. Adding one means removing one.

Plan

Eight weeks to launch

  1. Week 1

    Spec + this mock

    One-page spec. Put this preview in front of 5 developers and change it based on what they do with it.

  2. Weeks 2–4

    Core, CLI, terminal UI

    Copy in the proven engine, add intake, limit waiting and stay-awake. First overnight shift on a real repo.

  3. Weeks 4–6

    Web app + MCP

    The morning page and the 3 MCP tools, both on the same 4 actions.

  4. Weeks 6–8

    Shep 2 builds itself

    Shep 2's remaining work runs on its own night shift, in public. Then launch.
