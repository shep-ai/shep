Shep 2 · design research · October 2026

Everyone builds for watching. We build for the morning.

We studied Mac apps, terminal tools, agent CLIs and what is trending on 21st.dev, Dribbble, Mobbin and Pinterest. Every agent tool is designed around watching an agent work. Nobody designed the moment you wake up and decide what ships. That gap shapes everything below, including the look.

Mac appsAgent apps are chat rooms.

Conductor, Codex, Claude desktop and Cursor show one workspace at a time, sorted by time. None answers "what finished overnight, with proof?"

Competition"While you sleep" is taken.

Amp's homepage: "Send prompt, close laptop… continue while you sleep… forget worktrees." Our edge has to be the morning review.

PlatformThe Mac got a Dynamic Island.

Apple announced it on Oct 28. Live Activities also show in the menu bar. Only small notch hacks use this for agents.

TerminalAgent CLIs stop animating after the splash.

Codex, Gemini, Crush and Claude Code animate the welcome screen, then go static. Nobody built a calm screen for work you're away from.

Visual trendsASCII and dither are crowded.

Ghostty, Zed, Raycast and 21st.dev all use them. They only work for us if they carry meaning, so ours shows progress.

Dribbble, Pinterest, Behance and Mobbin blocked automated reading, so points about them come from search results and trend write-ups. Everything else was read directly. Sources are at the bottom.

The signature

The sky is the progress bar

One scene everywhere. Each task is a sheep. While agents work, the shepherd's lantern keeps watch. Each finished pull request walks a sheep into the pen and warms the horizon a little. When the last one is in, the sun is up. In the terminal it is plain characters, so it works over SSH. On the Mac it is the same scene, dithered.

Proposal 4 · Mac app

The review window

Sorted by verdict, not by time. Proof comes first: the screenshot is the hero and the diff is one key away. Single keys decide. The sidebar is glass over the dithered sky, and it brightens with every merge. Clear the queue and you get the sunrise.

  • Click the window, then press M merge, S send back, Space enlarge proof
  • Glass only on chrome, content on solid surfaces, so it stays readable

Guardrails

Wow without the cost

The research found the same failures across agent CLIs: flicker, battery drain, motion that ignores settings. These rules come from those bug reports.

Motion rules

  • One clock for every animation, about 20 frames a second, 10 or less over SSH. Paused when hidden.
  • Every frame wrapped in synchronized output (DEC 2026). Ghostty, Kitty, iTerm2, WezTerm and Windows Terminal support it.
  • One switch, --no-motion, turns off everything. Claude Code's setting left some animations running; ours won't.
  • Respect NO_COLOR, CI and non-interactive output. No blinking, ever.
  • Read the terminal's own background instead of painting over it. Codex does this.
  • The morning brief stays inline so search, scroll and copy keep working.

Leave out

  • Aurora gradients, sparkles, glowing orbs. They read as a template.
  • Purple-to-blue AI gradients. Our indigo always comes with amber and grain.
  • Liquid Glass on content. Chrome only. Apple itself added a frosted option after readability complaints.
  • Bento grids and logo marquees on the website.
  • ASCII or dither as decoration. Every effect must say something about progress or time.
  • A chat-first layout. That's every competitor. We lead with verdicts.

The stack

Rust core, native Mac app, no C++

One small Rust binary does the work and holds the CLI, terminal UI and MCP server. Every surface talks to it over one protocol. The Mac app is native SwiftUI, which is the only way to get the Dynamic Island, App Intents and true native feel. Codex and Ghostty are built this way.

Spike first: 5 days

Build one thin slice in Rust: add and start one task, run Claude Code in a worktree, save to SQLite, a board with one transition, the MCP tools, and a one-screen SwiftUI window.

Measure

Lines of code, agent fix loops, build time, binary size, cold start, idle memory. Optionally the same slice in Bun for 2 days.

Kill rule

If Rust takes more than 1.5 times as long as Bun for the same result, build Shep 2 in TypeScript on Bun with OpenTUI and keep the SwiftUI app.
