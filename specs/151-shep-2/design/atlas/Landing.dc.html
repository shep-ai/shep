Dependabot for your backlog

Go to sleep with issues. Wake up with pull requests.

Queue GitHub issues tonight. Your own coding agent works each one in its own worktree while you sleep. In the morning, review draft pull requests that already pass CI, with screenshots as proof, and press merge.

Install Shep brew install shep-ai/tap/shep

How a night works

TonightLabel issues shep, or run shep add, then shep go --at 23:00. Takes a minute.
OvernightEach task gets its own branch. Your agent writes the code, CI runs, red builds get fixed, screenshots get taken. If it hits a usage limit, it waits and resumes.
MorningOne notification. Review each draft PR with its proof, one key at a time: merge, send back, or answer a question.

Proof before you merge

Every pull request arrives with CI green, a screenshot or test run, and a second opinion from a separate review agent. If something needs you, it asks one clear question instead of guessing.

Shep only opens drafts. Nothing reaches your main branch until you press merge.

The agent you already use

Shep runs the coding agent CLI that's already on your machine, with your own login. It never sees or stores your keys, and it runs on your machine, not ours.
